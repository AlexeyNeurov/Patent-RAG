## Локальная разработка

1. Создайте отдельную ветку от `main`.
2. Подготовьте виртуальное окружение Python 3.10+.
3. Установите зависимости из `requirements.txt`.
4. Разместите тестовый индекс по инструкции из `data/README.md`.
5. Запустите `python -m compileall app.py src` и проверьте приложение командой `streamlit run app.py`.

## Pull request

В описании укажите задачу, суть решения, способ проверки и влияние на поисковое качество. Для изменений ранжирования приложите примеры запросов и сравнение выдачи до/после. Не добавляйте в коммит локальные базы Qdrant, выгрузки патентов, веса моделей, архивы и секреты.
